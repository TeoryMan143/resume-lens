# Test Design — Stage 1 (Regular Expressions) and Stage 2 (Finite-State Transducers)

ResumeLens · Computación y Estructuras Discretas III · 2026-2

This document describes the automated tests for the first two stages of the ResumeLens pipeline.
Every test case has an ID (`TC-E-xx`, `TC-N-xx`, `TC-I-xx`) that appears in the name of the matching
pytest function, so each row of this document can be traced to the code.

| Stage                          | Module under test                                                                         | Test file                           |
| ------------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------------- |
| 1. Information extraction      | `resume_lens.extraction` (`ResumeExtractor`, `ExtractionResult`, `patterns`)              | `tests/test_extraction.py`          |
| 2. Normalization — transducers | `resume_lens.normalization.transducers` (`CleaningTransducer`, `QualificationTransducer`) | `tests/test_transducers.py`         |
| 2. Normalization — normalizer  | `resume_lens.normalization.normalizer` (`QualificationNormalizer`)                        | `tests/test_normalizer.py`          |
| 2. Normalization — sorting     | `resume_lens.normalization.sorter` / `profiles`                                           | `tests/test_sorter.py`              |
| 1 → 2 integration              | `resume_lens.pipeline` (`ResumeLensPipeline`), `resume_lens.main`                         | `tests/test_pipeline_stages_1_2.py` |

**How to run**

```bash
pip install pytest          # or: uv add --dev pytest
pytest                      # runs everything under tests/
pytest -k "tc_e_"           # Stage 1 only
pytest -k "tc_n_"           # Stage 2 only
```

### 2.2 Stage 2 — `CleaningTransducer` and `QualificationTransducer`

**Objective:** verify that each transducer's 7-tuple M = (Q, Σ, Γ, δ, ω, q0, F) is the one documented and that
the translation relation is correct for words in and out of the language.

| ID      | Class                   | Method                          | Scenario | Input values                                                                          | Expected result                                                                                                                                                      |
| ------- | ----------------------- | ------------------------------- | -------- | ------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
